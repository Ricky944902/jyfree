## 一、这是什么

极域（Mythware）电子教室在 Linux 上把锁屏、监视、远程控制等功能实现为
**用户态进程内的函数调用**。

本工具用 `ptrace` 把一个很小的共享库（payload）注入进 `Student` 进程，
在那些函数入口安装钩子，让它们直接返回 —— 相应功能就不会发生。

```
jyfree (本工具, 用户态, 与 Student 同 UID)
 ├─ ptrace 注入: ATTACH → 远程 mmap → 远程 dlopen → DETACH
 ├─ 共享内存 /dev/shm/jyfree.state  ←→  特性位 / 计数 / 心跳
 └─ 看门狗: Student 崩溃或被 systemd 重启后自动重新注入

libjyfree.so (payload, 在 Student 进程内)
 ├─ 内联钩子 ×16   16 字节补丁, 无需 trampoline
 ├─ GOT 钩子 ×11   扫描所有已加载 ELF
 └─ 协调线程       心跳 + 新模块重扫
```

## 二、安装（不需要 root，不需要装任何库）

两个文件拷到 UOS 上就能跑：

```bash
chmod +x jyfree libjyfree.so
sudo jyfree          # 见下方"权限说明"
```

> ⚠️ `libjyfree.so` **必须和 `jyfree` 在同一目录**。
> 工具会从 `/proc/self/exe` 所在目录开始找它。

### 依赖要求

| 组件 | 依赖 | 说明 |
|---|---|---|
| `jyfree` | `libc.so.6` | **静态链接**，任何 Linux 都有 |
| `libjyfree.so` | `libc.so.6`（≥ GLIBC_2.17） | 任何 aarch64 glibc 都有 |

命令行版**不需要 X11**，也不需要 `pthread`/`libdl`/`librt` 之类的单独库。

---

## 三、权限说明（重要）

**不需要 root**，但**必须与 `Student` 同 UID**（`ptrace` 的硬性要求）。

极域通常随开机自启的桌面会话运行，那基本就是你的登录用户。

```bash
# 确认 UID 一致
id -u                              # 本工具
ps -o uid= -p $(pgrep Student | head -1)   # 极域
```

两者相同即可。若不同，用极域所属的用户运行：

```bash
su - <极域用户名>
```

## 四、开始使用

### 1. 先看状态（不改动任何东西）

```bash
./jyfree --process      # 极域的三个进程
./jyfree --modules      # Student 已加载哪些极域库
./jyfree --status       # 注入状态
```

### 2. 注入并进入交互模式

```bash
./jyfree
```

### 3. 交互命令

| 命令 | 说明 |
|---|---|
| `help` | 命令列表 |
| `status` | 注入状态、进程状态、已装钩子数 |
| `feat list` | 列出 7 个特性位 |
| `feat <名> on\|off` | 开关特性 |
| `capture <模式>` | `pass` / `freeze` / `black` / `white` |
| `counters` | **各特性拦截次数**（验证钩子是否生效） |
| `modules` | 已加载的极域库 + 计数 |
| `inject` / `uninject` | 手动注入 / 卸载还原 |
| `process` | 三个极域进程详情 |
| `freeze` / `thaw` | `SIGSTOP` / `SIGCONT` |
| `log [文件]` | payload 日志尾部 |
| `debug <0-5>` | 调试级别 |
| `quit` | 退出（自动还原钩子） |

### 4. 特性位一览

| 位 | 名称 | 拦什么 | 效果 |
|---|---|---|---|
| `0x01` | `lock` | `ShowLockScreen` / `ShowBlackScreen` | 锁屏、黑屏不出现 |
| `0x02` | `monitor` | `StartMonitorPassive` 等 3 个 | 教师看不到你的屏幕 |
| `0x04` | `command` | `ExecuteRemoteCmd` 等 2 个 | 远程命令不执行 |
| `0x08` | `apps` | `KillProcess` / `CloseTopWindow` 等 5 个 | 不被杀进程、不被关窗口 |
| `0x10` | `policy` | `UpdatePoliciesToService` 等 3 个 | 策略不下发到 root 服务 |
| `0x20` | `input` | freerdp 输入回调 + `XGrab*`/`XTestFake*` 等 | 教师键鼠无效 |
| `0x40` | `capture` | `XGetImage` / `XShmGetImage` | 截屏冻结或全黑 |

**改动立即生效**，不需要重新注入（特性位走共享内存）。

## 五、最低风险尝试步骤

真机首次测试请严格按顺序，一次只做一步。

### 第 1 步：只看不碰

```bash
./jyfree --process
./jyfree --modules
```

确认能找到 `Student` 进程。

### 第 2 步：注入，先不开任何拦截

```bash
./jyfree -d 5
```

观察输出：

- `已附加 Student: pid=NNNN`
- `注入成功, 已安装 N 个钩子`
- `payload 就绪: 是`

**如果这一步就失败，看第八章排错，不要继续。**

### 第 3 步：看 payload 日志

```bash
cat /tmp/jyfree-payload.log
```

正常应该有"已钩 xxx @ 0x..."的记录。出现 `写入失败` 或地址不匹配，
说明符号地址和你的极域版本对不上（见第九章）。

### 第 4 步：一次只开一个特性位

```bash
> feat list         # 确认当前都是开的, 先关掉一部分
> feat all off
> feat lock on      # 只开锁屏
> counters          # 此时应该全是 0, 正常
```

**然后让教师尝试锁屏**，再看：

```bash
> counters
  锁屏 1 <- 已拦截     ← 钩子生效了
```

如果 Student 崩溃或行为异常，立刻：

```bash
> uninject
> quit
```

### 第 5 步：确认无残留

```bash
> uninject
> quit
```

## 六、典型场景

### 只想不被锁屏

```bash
./jyfree
> feat all off
> feat lock on
> quit
```

### 课上全程防护

```bash
./jyfree
> feat all on
> feat capture off     # 先放行截屏, 免得影响正常操作
... 上课 ...
> counters             # 看拦了多少
> feat capture on      # 恢复
> quit
```

### 关闭屏幕广播窗口

```bash
# 教师开始广播后
./jyfree --modules      # 确认 libcast-x11.so 已加载
```

窗口关闭功能尚未实现（见第九章）。

## 七、开机自启（可选）

```ini
# ~/.config/systemd/user/jyfree.service
[Unit]
Description=jyfree

[Service]
Type=simple
ExecStart=%h/jyfree
Restart=always
RestartSec=3

[Install]
WantedBy=default.target
```

```bash
systemctl --user daemon-reload
systemctl --user enable jyfree.service
```

必须与 `Student` 同 UID 运行，所以用 **user 级**单元而非 system 级。

## 八、排错

```bash
cat /tmp/jyfree-payload.log   # payload 内部日志
./jyfree -d 5                 # 控制器详细日志
```

| 现象 | 原因 | 处理 |
|---|---|---|
| `未找到 Student 进程` | 极域没启动 | 启动后重新运行，或用看门狗等待 |
| `PTRACE_ATTACH 被拒绝` | UID 不一致 | `ps -o uid= -p $(pgrep Student\|head -1)` 对比 |
| `payload 未在超时内就绪` | 架构或符号不匹配 | 见第九章 |
| `目标进程处于 'T' 状态` | Student 被冻结 | `> thaw` |
| `counters` 全 0 | 正常 —— 教师还没操作 | 先看 `modules` 确认库已加载 |
| 截屏计数不涨 | 教师广播走 RDP 流，不同路径 | 见第九章 |

诊断信息收集：

```bash
{
  echo "=== 系统 ==="; uname -a
  echo "=== 进程 ==="; ./jyfree --process
  echo "=== 已加载库 ==="; ./jyfree --modules
  echo "=== 状态 ==="; ./jyfree -d 5 -s
  echo "=== payload 日志 ==="; tail -50 /tmp/jyfree-payload.log
  echo "=== 符号地址核对 ==="
  nm /opt/mythware/classroom-management/Student 2>/dev/null \
    | grep -E 'ShowLockScreen|StartMonitorPassive|ExecuteRemoteCmd'
} > /tmp/jyfree-report.txt 2>&1
```

## 九、换极域版本怎么办

符号地址硬编码在 `include/payload_state.h`，只适用于 **v2.7.3715 (2024-12-12)**。

在 UOS 上核对：

```bash
nm /opt/mythware/classroom-management/Student | grep -E 'ShowLockScreen|StartMonitorPassive'
readelf -s /opt/mythware/classroom-management/libGetAppsInfo.so.2 \
  | grep -E 'KillProcess|CloseTopWindow'
```

对比 `include/payload_state.h` 里的 `SYM_*` 常量，不一致就更新后重新编译。

## 十、已知限制

1. **符号地址硬编码**，仅适用 Student **v2.7.3715**
2. **开机已加载的策略无法从用户态更改**（`cms_nf.ko` 在内核侧）—— 只能阻断后续下发
3. **UDP 命令通道**（`4788/5512/5662/...`）协议未逆向，未做伪造
4. **QLocalServer 本地协议**未逆向（socket `srwxrwxrwx` 全局可连）
5. **教师广播是 RDP 流**，`capture` 可能不生效（待验证）
6. **Wayland 下 X11 钩子只影响 X 客户端** —— Student 在 XWayland，实测待确认
7. **关闭广播窗口**功能未实现
8. `setuid` 的 `Launcher` 明确不在本工具范围
