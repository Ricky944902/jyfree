# 03 · 使用手册

**[简体中文](03-使用手册.md)** · **[English](03-user-guide.en.md)**

## 1. 快速开始

```bash
# 1. 编译
make

# 2. 先看状态（不影响任何东西）
./bin/jyfree --process        # 极域进程
./bin/jyfree --modules        # 已加载的极域库

# 3. 注入（必须与极域同 UID，不需要 root）
./bin/jyfree

# 4. 在交互提示符里输入命令
help                          # 命令列表
status                        # 注入状态
counters                      # 拦截计数 ← 验证钩子是否生效
quit                          # 退出（自动卸载并还原钩子）
```

图形界面：

```bash
./bin/jyfree-gui              # 点「注入」按钮
./bin/jyfree-gui -i           # 启动后立即注入
```

---

## 2. 前提条件

| 条件 | 说明 |
|---|---|
| **同 UID** | 必须与 `Student` 同一用户运行（`ptrace` 要求）。**不需要 root** |
| aarch64 | 交叉编译或在 aarch64 机器上编译 |
| 已启动极域 | 极域启动后再注入；未启动时看门狗会自动等待并注入 |

检查 UID 是否一致：

```bash
# 极域的 UID
pgrep -a Student
ps -o uid= -p $(pgrep Student | head -1)

# 本工具的 UID
id -u
```

两者必须相同。

---

## 3. 命令行参数

```
用法: jyfree [选项]

  -i, --inject         注入 Student 并进入交互模式 (默认)
  -p, --process        显示极域进程后退出
  -m, --modules        显示已加载的极域库后退出
  -s, --status         显示注入状态后退出
  -c, --config FILE    加载配置文件
  -d, --debug N        调试级别 (0=关闭 ~ 5=最详细)
  -n, --no-watchdog    不启动看门狗
  -h, --help           显示帮助
```

示例：

```bash
./bin/jyfree -d 5               # 最详细日志
./bin/jyfree -i -n              # 注入但不启动看门狗
./bin/jyfree -c my.json         # 用自定义配置
```

## 4. 交互命令

进入交互模式后直接输入。

### 4.1 状态查询

| 命令 | 说明 |
|---|---|
| `status` | 注入状态、进程状态（含 `T` 停止态提示）、已装钩子数、当前特性位 |
| `process` | `Student` / `StudentAgent` / `StudentService` 三个进程的 PID、exe、cmdline、状态 |
| `modules` | `libcastng` / `libDesk` / `libGetAppsInfo` / `libcast-x11` / `libjyfree` 各自是否已加载 + 拦截计数 |
| `counters` | 各特性的拦截次数 |
| `config show` | 当前配置 |
| `log [文件]` | payload 日志尾部（默认 `/tmp/jyfree-payload.log`） |

### 4.2 特性位管理（核心）

`help` 会列出全部命令。特性位通过共享内存传给 payload，**改动立即生效，无需重新注入**。

```bash
feat list              # 列出全部特性位及开关状态
feat lock on           # 开启锁屏拦截
feat monitor off       # 关闭监视拦截
feat all on            # 全开
feat capture off       # 关闭截屏拦截
```

| 名称 | 位 | 拦截内容 |
|---|---|---|
| `lock` | `0x01` | `ShowLockScreen` 锁屏、`ShowBlackScreen` 黑屏肃静 |
| `monitor` | `0x02` | `StartMonitorPassive`、`StartRdpMonitorPassive`、`ProcessDeskMonitorCommand` |
| `command` | `0x04` | `ExecuteRemoteCmd`、`ProcessRemoteCommand` |
| `apps` | `0x08` | `KillProcess`、`CloseTopWindow`、`CloseApps`、`CloseWndByWindowId`、`DoAppPolicyControl` |
| `policy` | `0x10` | `UpdatePoliciesToStudentService`、`UpdateUsbPolicy...`、`UpdateWebPolicy...` |
| `input` | `0x20` | freerdp 输入回调 + `XGrabKeyboard/Pointer`、`XTestFake*`、`XWarpPointer`、`XkbLockModifiers`、`XSendEvent`(type 2-6) |
| `capture` | `0x40` | `XGetImage` / `XShmGetImage` 像素覆写 |
| `all` | `0x7F` | 全开 |

### 4.3 截屏模式

```bash
capture              # 显示当前模式
capture pass         # 放行 (教师看到真实画面)
capture freeze       # 冻结 (重复显示同一画面)
capture black        # 全黑
capture white        # 全白
```

> 非 `pass` 模式会自动开启 `capture` 特性位。

**注意**：截屏有**两条不同路径**——

1. **监视/截屏** → `libDesk.so.2` 的 `XGetImage`（本工具覆盖此路径）
2. **教师广播** → RDP 流走 `libcast-x11.so`（不同路径）

如果 `counters` 的「截屏」计数一直是 0，说明走的是第 2 条路径。

### 4.4 注入控制

| 命令 | 说明 |
|---|---|
| `inject` | 手动重新注入 |
| `uninject` | 卸载 payload（触发 destructor 还原所有内联钩子） |
| `freeze` | `SIGSTOP` 冻结 `Student` |
| `thaw` | `SIGCONT` 恢复 `Student` |

### 4.5 其他

| 命令 | 说明 |
|---|---|
| `debug <0-5>` | 设置调试级别 |
| `config show\|save\|load` | 配置管理 |
| `quit` | 退出（自动 `uninject` + 还原钩子） |

## 5. 配置文件

默认路径 `~/.config/jiyu-trainer/config.json`：

```json
{
  "debug_level": 3,
  "run_mode": 0,
  "enable_gui": false,
  "enable_log": true,
  "discovery_port": 4788,
  "auto_reinject": true,
  "feature_mask": 127,
  "capture_mode": 1,
  "log_file": ""
}
```

| 字段 | 含义 |
|---|---|
| `debug_level` | 0=关闭 1=错误 2=警告 3=信息 4=详细 5=跟踪 |
| `feature_mask` | 特性位掩码（十进制），`127` = 全开 |
| `capture_mode` | 0=pass 1=freeze 2=black 3=white |
| `auto_reinject` | 看门狗自动重注入 |

```bash
./bin/jyfree -c /path/to/my.json
```

## 6. 图形界面

```bash
./bin/jyfree-gui
./bin/jyfree-gui -i        # 启动即注入
./bin/jyfree-gui -d 4      # 提高日志级别
```

界面布局：

```
┌────────────────────────────────────────┐
│ jyfree - 极域绕过 (UOS)              v2 │
├────────────────────────────────────────┤
│ [注入] [刷新] [日志] [截屏:冻结]        │
│ [锁屏拦截] [监视拦截] [命令拦截]         │
│ [输入拦截] [策略拦截] [应用拦截]         │
│                                        │
│ Student ●    Payload ●                 │
│ 已装钩子    拦截次数                    │
├────────────────────────────────────────┤
│ 就绪 - 点击注入开始                     │
└────────────────────────────────────────┘
```

- **注入**：执行 ptrace 注入
- **刷新**：更新进程/钩子/计数状态
- **日志**：打开实时日志窗口（滚轮滚动，ESC 关闭）
- **截屏**：循环切换 放行 → 冻结 → 全黑
- 六个特性位按钮：点击切换开关

日志窗口显示**控制器**日志。payload 内部日志在 `/tmp/jyfree-payload.log`。

## 7. 看门狗

默认开启（`-n` 可禁用）。每秒轮询：

1. `Student` pid 变化 → 新实例 → 重新注入
2. `Student` `start_time` 变化（防 pid 复用） → 重新注入
3. payload 心跳停滞 5 秒 → 重新注入

**为什么需要**：实测 `Student` 会因 `QThread destroyed while running` abort，
被 `StudentAgent` 自动重启，注入随之失效。看门狗负责恢复。

查看是否在工作：

```bash
./bin/jyfree -d 4     # 会打印「检测到 Student 新实例 (pid=NNN), 重新注入」
```

## 8. systemd 常驻

```bash
systemctl --user daemon-reload
systemctl --user enable jyfree.service
systemctl --user start jyfree.service

# 看日志
journalctl --user -u jyfree.service -f
```

单元文件内容见 `deploy/jyfree.service`。它是 **user 级**（不是 system 级），
因为必须与 `Student` 同 UID。

> 极域自己的单元 `com.mythware.mcm-student.service` 设了
> `RefuseManualStop=yes`，不能用 `systemctl --user stop` 停它，
> 只能直接发信号。

## 9. 卸载还原

```bash
./bin/jyfree          # 交互模式
> uninject            # 触发 payload destructor, 还原所有内联钩子
> quit
```

或者直接 `quit`（会自动 `uninject`）。

GOT 钩子**不做还原** —— 进程即将退出或后续会重注入，意义不大；
且 GOT 里存的是原函数地址，覆盖后调用仍走原函数（payload 保留了原指针）。

## 10. 典型工作流

### 课堂全程防护

```bash
./bin/jyfree
> status
  Student 进程:   PID=12345
  payload 就绪:   是
  已装钩子数:     16
  当前开启:       锁屏 监视 命令 应用 策略 输入 截屏

> feat capture off      # 先放行截屏, 免得影响正常操作
... 上课 ...
> counters
  锁屏 3 <- 已拦截
  监视 1 <- 已拦截
  输入 12 <- 已拦截
> feat capture on       # 恢复截屏拦截
> quit
```

### 只想要"不被锁屏"

```bash
./bin/jyfree
> feat lock on
> feat monitor off
> feat command off
> feat input off
> feat apps off
> feat policy off
> feat capture off
> quit
```

### 排查钩子为何没生效

```bash
./bin/jyfree -d 5
> modules      # 对应的库加载了吗?
> counters     # 计数有增长吗?
> log          # payload 内部发生了什么
```

## 11. 依赖文件

| 路径 | 内容 |
|---|---|
| `/dev/shm/jyfree.state` | 共享内存（特性位、计数器、心跳） |
| `/tmp/jyfree-payload.log` | payload 内部日志 |
| `~/.config/jiyu-trainer/config.json` | 配置文件 |
| `~/.config/jiyu-trainer/jiyu-trainer.log` | 控制器日志（10MB 轮转） |

查看共享内存：

```bash
ls -l /dev/shm/jyfree.state
```
